📖 Panduan Penggunaan Aplikasi Absensi Driver

Panduan ini dibuat untuk membantu petugas security/satpam dalam menggunakan aplikasi absensi driver. Semua tombol, fungsi, dan cara pakai dijelaskan langkah demi langkah.

💡 Info Singkat:
Aplikasi ini menggantikan pencatatan absensi manual di Excel. Data otomatis tersimpan di Google Sheets (cloud), jadi tidak akan hilang dan bisa dilihat dari mana saja.

1. Apa Itu Aplikasi Ini?

Absensi Driver adalah aplikasi berbasis web untuk mencatat jam kerja driver setiap hari. Aplikasi mencatat:

  • Jam OUT — jam berangkat / keluar
  • Jam IN — jam pulang / kembali
  • Per driver, per hari, per bulan

Keunggulan:

  • ✅ Tampilan seperti Excel — tidak asing lagi
  • ✅ Bisa dipakai offline (saat WiFi mati)
  • ✅ Data otomatis tersimpan ke Google Sheets
  • ✅ Bisa export Excel, print, dan hitung kinerja
  • ✅ Tidak perlu install aplikasi — cukup buka di Chrome

2. Cara Buka Aplikasi di Tablet

1Pastikan tablet terhubung WiFi (kalau WiFi mati, aplikasi tetap bisa, tapi nanti sync saat WiFi nyala lagi).
2Di layar utama (home screen) tablet, cari icon bernama Absensi Driver (ada gambar tabel/absen).
3Tap icon itu — aplikasi akan terbuka otomatis di Chrome.
4Tunggu 2–3 detik sampai tabel muncul.
⚠ Kalau icon tidak ada:
Buka Chrome → ketik di address bar: brownisdonat8-tech.github.io/absensi-driver → tunggu muncul → tap menu (⋮) → Add to Home screen.

4. Penjelasan Semua Tombol

Toolbar memiliki tombol-tombol ini (dari kiri ke kanan):

← OKTOBER 2026 → ⚙ Driver 🔄 Sync 📤 Export Excel 📊 Matrix 📥 Upload Matrix 🖨 Print ⏱ Ringkasan ❓ Panduan

Tombol ← dan → (Bulan Lalu / Bulan Depan)

Untuk pindah bulan. Tekan ← untuk lihat bulan sebelumnya, → untuk bulan berikutnya. Teks di tengah menunjukkan bulan yang sedang tampil (misal: OKTOBER 2026).

Tombol ⚙ Driver (Hijau)

Untuk mengelola daftar driver — tambah driver baru, ubah nama, atau tandai resign.

Tombol 🔄 Sync (Biru Muda)

Untuk paksa ambil data terbaru dari Google Sheets. Gunakan kalau ada perubahan dari PC (admin) dan ingin langsung lihat di tablet.

Tombol 📤 Export Excel (Oranye)

Untuk download data absensi dalam bentuk file Excel (.xlsx). Bisa pilih bulan atau rentang tanggal tertentu.

Tombol 📊 Matrix (Ungu)

Untuk membuat sheet baru di Google Sheets bernama "Matrix" yang tampilannya persis seperti di tablet. Berguna untuk admin yang mau lihat/edit data dalam format Excel.

Tombol 📥 Upload Matrix (Teal)

Kebalikan dari Matrix. Kalau admin mengedit data di sheet "Matrix" dari PC, tekan tombol ini untuk menarik perubahan ke tablet.

Tombol 🖨 Print (Oranye)

Untuk mencetak tabel ke printer atau simpan sebagai PDF. Hasil print rapi (toolbar & tombol tidak ikut tercetak).

Tombol ⏱ Ringkasan (Ungu Tua)

Untuk menghitung total jam kerja setiap driver per hari (durasi OUT → IN). Bisa difilter per bulan atau rentang tanggal, dan bisa diexport ke Excel.

Tombol ❓ Panduan (Merah)

Untuk membuka halaman panduan ini. Klik → akan terbuka di tab baru.

5. Cara Input Jam Kerja

Ini kegiatan utama sehari-hari. Ikuti langkah ini:

1Cari nama driver di kolom NAMA (kiri). Contoh: VIRLA.
2Cari kolom tanggal hari ini (lihat nama hari & tanggal di header). Contoh: SENIN 05-Okt-26.
3Ada 2 sub-kolom: OUT (hijau) dan IN (hijau muda).
4Tap kotak di bawah OUT — muncul input jam.
5Atur jam berangkat (misal 07:30). Tap OK/Set.
6Kotak akan berkedip hijau = berhasil tersimpan.
7Saat driver pulang, tap kotak di bawah IN. Atur jam pulang (misal 15:45). Tap OK.
✅ Selesai! Data otomatis tersimpan ke Google Sheets (kalau ONLINE). Kalau OFFLINE, data disimpan sementara di tablet, nanti otomatis terkirim saat WiFi nyala.

Tanda Warna Kotak Input:

WarnaArtinya
KuningSedang dipilih (aktif)
HijauData berhasil terkirim ke Google Sheets
OranyeData disimpan sementara (offline), belum ter-sync
PutihBelum ada input / kosong

6. Kelola Daftar Driver

Kalau ada driver baru masuk, atau driver resign, kamu bisa ubah daftarnya di sini.

1Tap tombol ⚙ Driver
2Akan muncul kotak daftar driver.

Cara Tambah Driver Baru:

1Di baris atas, isi Nama Driver Baru (contoh: ANDI).
2Isi Mulai Aktif (tanggal mulai kerja).
3Tap + Tambah.
4Nama akan muncul di daftar. Tutup kotak, lalu refresh halaman untuk lihat di tabel.

Cara Ubah Nama Driver:

1Cari nama driver di daftar.
2Ubah nama di kotak input.
3Tap Simpan di baris itu.

Cara Tandai Driver Resign:

1Cari nama driver di daftar.
2Isi Resign dengan tanggal terakhir kerja.
3Tap Simpan.
4Driver akan hilang dari tabel bulan berikutnya. Data lama tetap aman.
ℹ Catatan: Driver yang di-resign tidak dihapus dari sistem, hanya disembunyikan. Kalau masuk kerja lagi, tinggal kosongkan kolom Resign dan klik Simpan.

7. Export ke Excel

Untuk membuat file Excel dari data absensi (bisa diprint atau dikirim via email/WhatsApp).

1Tap tombol 📤 Export Excel.
2Muncul kotak dialog Export.
3Pilih Bulan dan Tahun (default: bulan sekarang).
4Kalau mau rentang tanggal tertentu, centang Pakai rentang tanggal, isi Dari dan Sampai.
5Tap 💾 Download Excel.
6File otomatis ter-download (cek di folder Download tablet).
💡 Contoh: Untuk laporan bulanan Oktober 2026, pilih Bulan=OKTOBER, Tahun=2026, klik Download. Untuk laporan 1–15 Oktober saja, centang range dan isi tanggalnya.

8. Print / Cetak

Ada 2 cara print:

Cara 1: Print bulan yang sedang tampil

1Pastikan bulan yang tampil sesuai keinginan (misal OKTOBER 2026).
2Tap tombol 🖨 Print.
3Muncul preview print.
4Pilih printer, atau pilih Save as PDF untuk simpan file.
5Tap Print / Save.

Cara 2: Print range tanggal (misal 1–15 Okt saja)

1Tap 📤 Export Excel.
2Centang Pakai rentang tanggal, isi Dari dan Sampai.
3Tap 🖨 Print Range Ini (tombol abu-abu di bawah Download Excel).
4Preview print akan muncul dengan data range tersebut.

9. Ringkasan Kinerja

Fitur ini menghitung durasi kerja setiap driver (jam IN dikurangi jam OUT). Sangat berguna untuk menilai kinerja driver.

1Tap tombol ⏱ Ringkasan.
2Pilih Bulan dan Tahun.
3Kalau mau range tanggal (misal 1–15 Okt), centang Pakai range tanggal dan isi Dari & Sampai.
4Tap 🔍 Tampilkan.
5Akan muncul tabel durasi per driver per tanggal.
6Kalau mau simpan ke Excel, tap 💾 Export XLSX.

Cara Membaca Hasil Ringkasan:

Kolom / TandaArtinya
8:15Driver bekerja 8 jam 15 menit hari itu
? (latar merah)Jam OUT atau IN tidak lengkap
KosongDriver tidak bekerja hari itu
Kolom TOTAL (hijau)Total jam kerja driver selama periode
GRAND TOTAL (bawah)Total seluruh driver selama periode
Header bulan (ungu)Kalau range lintas bulan, header dipisah per bulan
💡 Contoh: Driver VIRLA tanggal 1 Okt: OUT=07:30, IN=15:45 → ringkasan menampilkan 8:15. Total kolom kanan menunjukkan akumulasi seluruh bulan.

10. Sinkronisasi Matrix

Fitur ini untuk admin yang mau edit data di Google Sheets (dari PC) dengan tampilan seperti Excel.

📊 Matrix — HTML → Google Sheets

Kalau kamu sudah input banyak data di tablet, dan mau admin lihat di Google Sheets dalam format Excel:

1Tap 📊 Matrix.
2Konfirmasi → tunggu beberapa detik.
3Buka Google Sheets di PC → akan muncul sheet baru "Matrix".

📥 Upload Matrix — Google Sheets → HTML

Kalau admin sudah edit di sheet "Matrix" dari PC, mau bawa perubahan ke tablet:

1Pastikan admin sudah selesai edit di Google Sheets.
2Di tablet, tap 📥 Upload Matrix.
3Konfirmasi → tunggu notifikasi "Sync dari Matrix selesai".
4Tabel di tablet otomatis refresh dengan data terbaru.
⚠ Hati-hati: Tombol Upload Matrix akan menimpa data di sheet "Data" dengan isi sheet "Matrix". Pastikan sheet "Matrix" sudah benar sebelum upload.

11. Mode Offline (Kalau WiFi Mati)

Aplikasi tetap bisa dipakai walau WiFi mati. Data disimpan sementara di tablet, lalu otomatis dikirim ke Google Sheets saat WiFi nyala lagi.

Cara Tahu Sedang Offline:

Lihat badge di kanan atas: OFFLINE (merah).

Apa yang Bisa Dilakukan Saat Offline:

  • ✅ Input jam OUT/IN driver (tetap bisa)
  • ✅ Lihat data lama (dari cache tablet)
  • ❌ Tambah/ubah driver (butuh internet)
  • ❌ Export Excel (butuh internet)
  • ❌ Buat Matrix (butuh internet)

Apa yang Terjadi:

  • Saat offline: kotak input akan berkedip oranye = data disimpan di antrian
  • Badge jadi PENDING 3 = ada 3 data belum terkirim
  • Saat WiFi nyala: badge SYNC... → data otomatis terkirim
  • Setelah selesai: badge kembali ONLINE
✅ Data Anda aman! Selama tidak menghapus cache Chrome, data offline akan tersimpan sampai berhasil terkirim.

12. Kalau Ada Masalah

MasalahSolusi
Tabel tidak muncul / kosong 1. Cek koneksi WiFi.
2. Tap 🔄 Sync.
3. Kalau masih kosong, tutup Chrome, buka lagi.
Tulisan ONLINE tapi data tidak muncul Tekan Ctrl + Shift + R (hard refresh) atau tutup-buka aplikasi.
Input jam tidak tersimpan Cek badge: kalau OFFLINE, tunggu WiFi nyala. Data akan otomatis terkirim.
Tombol tidak berfungsi Tutup aplikasi, buka lagi. Kalau perlu restart tablet.
Data driver tidak muncul di tablet Tap 🔄 Sync → tunggu badge kembali ONLINE.
Halaman tidak update setelah admin edit di PC Tekan Ctrl + Shift + R (Windows) atau clear cache Chrome → buka ulang.
Baterai tablet cepat habis Tutup aplikasi saat tidak dipakai (swipe dari daftar aplikasi).
🚨 Kalau Semua Cara Gagal:
1. Catat kejadian (tanggal, jam, apa yang dilakukan).
2. Screenshot layar.
3. Hubungi admin/IT support.
4. Sebagai cadangan: catat manual di kertas, input ulang nanti.
